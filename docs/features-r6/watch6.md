# Round 6 rows: watchers (watch6)

Core `crates/core/src/watch.rs`. Hosted by the menu bar agent (tray6); routes opened by the app (health6). Tests in `crates/core/tests/watch_events.rs` use real file system events (inotify here, FSEvents on a Mac) on a FakeMac temp folder.

| ID | Capability | How | Test | Status |
|---|---|---|---|---|
| W1 | Drag-to-Trash offer: an app dragged to the Trash that left files behind gives one notification ("Editor was moved to the Trash" / "4 items it left behind use 3.36 MB.") that opens App Remover on a plan of those leftovers (route `UninstallApp(<trashed path>)`) | `notify` watch on `~/.Trash` (non-recursive); new `*.app` names only; App Remover's own rules (`uninstaller::push_leftovers`); `watch::trashed_app_plan` builds the plan (leftovers only, App Remover's usual preselection), previewed and confirmed in the app | core watch_events::app_dragged_to_the_trash_gives_one_offer_with_its_leftovers, watch_events::the_plan_from_the_offer_runs_through_the_normal_confirmation, watch_events::the_trash_plan_refuses_paths_that_are_not_an_app_folder_in_the_trash | PARTIAL: core and events tested; the notification (tray6) and the App Remover page opened on the route (health6/apps6) are not built here; MAC-CHECK for FSEvents on the real Trash |
| W2 | No offer for apps CleanCraft moved, duplicates, apps still installed, apps that left nothing, partial copies | Journal lookup (`Moved.stored`), seen-list per bundle id (24 h, persisted), installed-id check, size/file-count/mtime signature stable for the debounce and Info.plist present | watch_events::an_app_cleancraft_moved_to_the_trash_gives_no_offer, a_second_copy_of_the_same_app_and_a_restart_give_no_second_offer, an_app_without_leftovers_or_still_installed_gives_no_offer, a_bundle_still_being_copied_waits_until_its_size_settles | WORKS (core) |

| W4 | New app or startup item watch: new or changed items in /Applications, ~/Applications, ~/Library/LaunchAgents, /Library/LaunchAgents, /Library/LaunchDaemons checked with Threat Check's rules; event only on a rule match, unsigned or ad hoc program, Gatekeeper rejection; opens Threat Check (route `Scan(Malware)`, finding in `WatchEvent::paths`) with the finding selected for review | `malware::launch_item_findings`, `malware::app_findings` (codesign and spctl through env.sys); `watch::preselect_threat` only ticks an item the scan listed; never quarantines | watch_events::an_unsigned_launch_agent_gives_an_event_that_opens_threat_check_on_it, signed_launch_agents_and_daemons_give_no_event_and_ad_hoc_ones_do, a_changed_agent_is_checked_again_but_reported_once, folders_that_appear_later_are_watched_and_turned_off_watches_stay_off | PARTIAL: core tested; route handling in the app is health6's; MAC-CHECK FSEvents on /Library folders |
| W5 | Rate limits: one notification per item, bursts coalesced, pause flag, quiet hours | Seen-list (`watch-seen.json` in the data folder), one item per bundle or plist, findings within `coalesce` merged per kind ("3 new startup items need a look"), `set_paused` drops events, quiet hours hold events until they end | watch_events::an_installer_writing_many_files_and_several_agents_is_coalesced, paused_watcher_drops_events_and_resumes_without_replaying, quiet_hours_hold_events_until_they_end, watch::tests::quiet_hours_span_midnight | WORKS (core) |
| W6 | The watcher never cleans | Never calls the executor; tests check the journal stays empty and no launchctl, osascript, mv or admin command ran | every watch_events test via assert_nothing_moved / journal checks | WORKS (core) |
