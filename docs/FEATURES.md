# CleanCraft features (the contract)

Every row is one user-facing capability. CleanCraft aims for feature parity with the reference app (the reference vendor) as described in its public documentation (research notes with sources: [research/the reference app-public.md](research/the reference app-public.md)). Names, texts, layout and icons are CleanCraft's own.

**Status** values:
- **WORKS**: an end-to-end test drives the UI by clicks and typing on a fake home folder, checks the files that actually moved and the numbers shown against a recalculation, and covers the error paths that apply.
- **PARTIAL**: some of the row works and is tested; the row says what is missing.
- **PLANNED**: not built yet.
- **EXCLUDED**: deliberately left out; the row says why.
- **MAC-CHECK**: logic tested on the fake home, but the real behaviour depends on macOS and must be confirmed by hand (see the hand-check list at the end).

**Risk**: Low = rebuilt automatically. Medium = something is lost but not personal (history, re-downloadable attachments). High = personal files or app parts, never preselected.

**Test** names refer to test functions (`crate::file::function`). Safety rules that apply to every row are in section 0.

## Hand-check list (on your Mac)

The full list, with exact commands and expected output, is in [agents/reports/checker.md](agents/reports/checker.md#hand-checks-on-a-real-mac) (H-S1 to H-U1). Run as your normal admin user. The ones that matter most, in order:

1. Install and open the app (H-U1), then Full Disk Access: banner, Open Privacy Settings, Check Again (H-S1).
2. Safety on real files: a file open in Preview is skipped (H-S2); `~/documents` typed in lower case is refused (H-S9); Pictures holding the Photos library cannot be selected in Disk Map (H-S10); Undo after emptying the Trash (H-S7).
3. System Junk on your Mac: which items are locked or need the password (H-J1); one administrator move with the password and its Undo (H-J2, H-P1).
4. Trash Bins: the Finder Automation prompt and Empty Trash (H-T1).
5. Mail Downloads with and without Full Disk Access (H-M1, H-M2).
6. Tune-up commands and the password dialog, including Cancel (H-K1, H-R2).
7. Startup Items: turn a login item and a user agent off and on, Undo from History (H-L1, H-L2).
8. App Remover on a drag-installed app and on a `.pkg` app, with Undo (H-A2); App Updates on a Sparkle app (H-A4).
9. Live Monitor numbers against Activity Monitor and System Settings > Battery (H-R1).
10. Verify the Threat Check rule list against public sources before relying on it (H-P3).
